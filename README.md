Я розробив HTML-сторінку персонального сайту викладача на основі попередньо створеного макету.

Сторінка складається з основних блоків. У верхній частині розміщено header, де знаходиться ПІБ викладача та його посада. Це дозволяє користувачу одразу зрозуміти, чию сторінку він відкрив.

Основна частина сторінки реалізована за допомогою контейнера з трьома колонками. Для цього було використано CSS властивість display: flex, яка дозволяє зручно розмістити блоки в один ряд.

Ліва частина містить фотографію викладача та контактну інформацію. Це зроблено для швидкого доступу до зв’язку.

Центральна частина є основною. У ній розміщена інформація про викладача, предмети та розклад занять. Саме тут знаходиться найважливіший контент.

Права частина містить додаткову інформацію, таку як оголошення та новини. Це допомагає інформувати студентів про зміни.

Для оформлення сторінки було використано CSS. Задано кольори, відступи, шрифти та структуру. Це зробило сторінку більш зручною та зрозумілою.

Таким чином, сторінка відповідає вимогам завдання, є простою у використанні та логічно структурованою.
